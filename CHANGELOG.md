# Changelog

## [0.1.0.0] - 2026-10-25

### Added

- Read the car's engineering conclusion, mapping results, hardware notes,
  and remaining navigation work in one linked portfolio.
- Build the used ROS telemetry bridge and run its offline timing regression.
- Inspect the reference-only ESP32-S3 profile and firmware provenance limits.
- See explicit Maker's Pet and Kaia.ai credits and retained Apache-2.0 licenses.

### Changed

- Explain the final ESP32/PC architecture separately from earlier Arduino
  and SLAM V2 experiments.
- Separate historical test measurements, owner-reported stable mapping,
  suspected latency, and unverified moving-navigation performance.
- Declare the bridge's direct TF dependencies and retain its required decoders.

### Removed

- Superseded Arduino motor and standalone Python LiDAR prototypes from the
  active tree; their history remains available.
- Unused telemetry test-publisher application from the curated bridge.
